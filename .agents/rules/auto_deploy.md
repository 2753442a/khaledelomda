# قاعدة الرفع والنشر المباشر عند التعديل (Auto-Deploy on Changes)

## القاعدة الأساسية:
عند إجراء أي تعديل أو إصلاح أو إضافة على ملفات المشروع البرمجية:
1. **التحقق والبناء (Build Verification):**
   - تشغيل `npm run build` للتأكد من خلو المشروع من أخطاء الـ Typescript والـ Bundling.
2. **الحفظ والرفع الفوري إلى المستودع (Git Commit & Push):**
   - تنفيذ `git add .` وعمل Commit واضح للتعديلات.
   - دفع التعديلات فوراً إلى المستودع الأساسي: `git push origin main`.
3. **التأكد من التحديث المباشر للموقع الحي (Live Deployment):**
   - التأكد من رفع الـ Bundle إلى Cloudflare Pages / Workers ليكون الموقع الحي `https://khaledelomda.pages.dev` محدثاً بالكامل فور إبلاغ المستخدم.
4. **ممنوع إبلاغ المستخدم باكتمال أي تعديل قبل رفعه الفعلي ومزامنته مع السيرفر الحي.**
