# منتجع و استراحة خالد العمدة

تطبيق ويب عربي RTL لمنتجع واحد: واجهة الضيوف، الحجز، الحساب، ولوحة إدارة المالك. الواجهة مبنية بـ React وTypeScript وVite، والبيانات والصلاحيات والحجوزات تعتمد على Supabase/PostgreSQL.

## التشغيل

1. انسخ `.env.example` إلى `.env.local` وضع عنوان المشروع ومفتاح `anon` أو `publishable` من إعدادات Supabase. المفتاح العام مصمم للاستخدام في الواجهة؛ لا تضع `service_role` هنا مطلقًا.
2. شغّل `npm install` ثم `npm run dev`.
3. طبّق ملفات `supabase/migrations` بالترتيب باستخدام Supabase CLI أو SQL Editor.
4. أضف أسرار Edge Functions الموضحة في `docs/operations.md`، ثم انشر الدوال.
5. للمعاينة فقط، نفّذ `supabase/seed.sql` بعد الترحيلات؛ يضيف بيانات معنونة بوضوح ويُبقي وضع القراءة فقط مفعّلًا.
6. أنشئ حساب المالك وتهيئته مع بقاء Demo مفعّلًا، ثم استبدل بيانات العرض من لوحة المالك. لا توقف Demo حتى يراجع المالك البيانات التشغيلية ويعتمدها.

## إعداد Supabase

- يستخدم التطبيق رقم الجوال كاسم الدخول، ويحوّله داخليًا إلى بريد اصطناعي غير قابل للاستلام لأن Supabase Auth يطلب بريدًا أو هاتفًا. عطّل تأكيد البريد في Authentication؛ لا تفعّل Phone provider. أرقام الجوال تبقى غير موثقة، ولا يُرسل OTP أو بريد.
- اضبط عنوان الموقع وروابط إعادة التوجيه في Authentication، وأضف نطاق الإنتاج.
- أنشئ نسخة احتياطية قبل تشغيل الترحيل على مشروع يحوي بيانات.
- حدّث أسماء المنتجع وموقعه وسياساته ومحتواه ومعلومات الحساب البنكي من لوحة المالك؛ القيم التشغيلية غير المفترضة.
- التحويل البنكي يبقى معلقًا حتى يطابقه المالك مع كشف الحساب. النقد يُسجّل بعد استلامه. مدة التحويل الافتراضية 24 ساعة وقابلة للتعديل.
- الدفع الإلكتروني متوقف بقيد قاعدة بيانات، وليس مجرد خيار واجهة.

## النشر

انشر `dist/` على Vercel أو Netlify أو Cloudflare Pages، وأضف متغيرات `VITE_*` العامة في إعدادات البناء. يستخدم التطبيق hash routing ولا يحتاج إعادة كتابة مسارات العميل على الخادم. اضبط عنوان الموقع وروابط إعادة التوجيه في إعدادات Supabase Auth، لا في متغير `VITE_SITE_URL`.

راجع `docs/operations.md` للتشغيل الآمن، إعداد الصور، تهيئة المالك، وحالة الدفع. الدفع الإلكتروني لا يعلن نجاحًا وهميًا؛ يلزم إعداد مزود ومفاتيح سرية على الخادم قبل تفعيله.

قبل أي إطلاق، تأكد من اعتماد اسم المنتجع والمحتوى والسياسات، ومطابقة مشروع Supabase المستهدف، واختبار الحجوزات والصلاحيات على بيئة مرحلية.
